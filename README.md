# 🎓 Internship Management System

A full-stack web application to manage student **internship programs** — tracking students, companies, and internship progress in one place.

---

### 🛠️ Tech Stack

**Backend:** **Spring Boot** (Java) · REST API
**Frontend:** **React** (Create React App) · **React Router** · **Tailwind CSS**
**Authentication:** **JWT** (JSON Web Token)

---

### ✨ Features

- 🔐 **User authentication** with JWT (login / secure session)
- 👨‍🎓 Manage student internship records
- 🏢 Manage partner companies
- 📊 Track internship status and progress
- 🎨 Responsive UI built with **Tailwind CSS**

---

### 📁 Project Structure
internship-management-system/
├── Server/ # Backend - Spring Boot (Java) REST API
├── client/ # Frontend - React + Tailwind CSS
└── .vscode/ # Editor config



---

### 🚀 Getting Started

**Backend (Server):**
```bash
cd Server
# Run with Maven
mvn spring-boot:run
```

**Frontend (client):**
```bash
cd client
npm install
npm start
```

The app will run at `http://localhost:3000` (frontend) and connect to the **Spring Boot** API.
